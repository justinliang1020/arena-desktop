are.na is "online software for saving and organizing the content that is important to you." On desktop computers, it is traditionally accessed via web browser.

The (unofficial) are.na desktop app allows you to access the are.na application as a dedicated application, separate from your web browser. It offers a minimalist, clean interface to use are.na from. This app simply wraps the existing are.na website and modifies it slightly to make it a desktop app.

This project is created by Justin Liang and is available open-source on Github.

Are.na Desktop App

Download for macOS

* DISCLAIMER: this application is NOT officially affiliated with are.na. This is a fan-made project by Justin.

Yup! This desktop app is just a wrapper over the existing are.na website. Nothing too fancy here. It's nice as a simple, distraction-free alternative to using are.na in your web browser. No tabs to think of, just windows.

I made this app so I could avoid distractions that came from using are.na in a web browser. In a web browser, I would always open new tabs and doom-scroll some random other website.

Hope you like it! Reach out to Justin for any feature requests or bug reports.

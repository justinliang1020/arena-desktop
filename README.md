## Developers Guide

1. Install Dependencies

```sh
pnpm install
```

2. Run Application

```sh
pnpm start
```

3. Package Application

```sh
pnpm package
```

## Publishing

1. Add GITHUB_TOKEN to `.env`. Scopes should have `content: write` for this repo.

```
GITHUB_TOKEN=***
```

2. Publish application

```sh
pnpm run publish
```

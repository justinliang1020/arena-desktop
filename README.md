## Developers Guide

1. Install Dependencies

```sh
pnpm install
```

2. Run Application

```sh
pnpm start
```

3. Package Application

```sh
pnpm package
```

## Publishing

1. Make application

```sh
pnpm make
```

2. Publish application (requires valid GITHUB_TOKEN)

```sh
pnpm run publish
```
